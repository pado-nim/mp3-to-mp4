MP3 → MP4 변환기
================

MP3 여러 개 + 배경 사진 → 곡 제목이 뜨고 연속 재생되는 MP4 한 개
(유튜브 설명란용 타임스탬프 _chapters.txt 도 같이 만들어 줌)

[처음 한 번]
  1_install.bat 더블클릭 → 파이썬 확인, 필요한 것 설치, ffmpeg 받기, 바탕화면 바로가기 생성

[쓰는 법]
  1. 바탕화면 "MP3 to MP4 변환기" (또는 2_run.bat) 실행
  2. ＋ 추가 로 MP3 넣기 → ▲▼ 로 순서 바꾸기 → 더블클릭으로 화면에 나올 제목 수정
  3. 사진 고르기 로 배경 선택 → MP4 만들기 → 저장 위치 고르면 끝

이 폴더는 옮기지 말고 그대로 두세요 (옮기면 1_install.bat 를 다시 실행).
